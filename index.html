Euler order XYZ. Position is in multiples of scene radius, scale is log-mapped. Locked outside Correct — this cannot be animated, keyframed, or routed to audio, and it is not the same thing as a per-region transform. Rotate X 180° is the default Y-down correction most captures need.

Opacity per-splat cull
—

—

Size and shape are independent failure modes — a needle can be small in volume and still streak hundreds of pixels — so Anisotropy limit is not a duplicate of Max splat size. It modifies geometry and costs real detail; reach for the Points section's Antialias floor first.

Opacity × all is a peak-alpha multiply applied before Spark's own minimum-alpha discard, so it both dims the model and thins it — but measured on a 44k capture the dimming dominates by a long way: at ×0.25 the brightest pixels are down 93% while the lit area is down only 3%. Expect a fade, with a secondary erosion at the edges. Above 1× is not "more": Spark's fragment shader gives alpha over 1 a different, sharper-topped falloff, so it reads as harder-edged discs. It does not replace Min opacity, which is the only one of these that touches diffuse low-alpha haze.

Masks sdf, 6 slots

Own dyno SDF per slot — sphere/box/ellipsoid/cylinder/capsule/plane, all evaluated unconditionally so no shape change ever recompiles. Centre and size are in units of scene radius. Shrink softens splat scale toward the edge, replacing the old Reveal effect's shrink-into-edge (a plane region in Cut mode reproduces it). Colorize R/G/B only apply in Colorize mode. Any of Noise / Saturation / Tint / Opacity below can be scoped to one of these four slots via its own Mask control in the lane — independent of what this slot's own Mode is doing.

Points point cloud + mesh

Pulls every splat toward one small, uniform dot, so the capture reads as a point cloud. The splats are still Gaussians, so very small dots thin out and darken the image; raise Opacity × all (Scene tab) or route audio onto it to compensate. Scope it to one mask with the lane's Mask control.

A coarse wire mesh through a thinned-out set of splat centres — keeps the gist of the geometry, not the detail. Built once, then drawn in a single pass, so it costs almost nothing per frame. It sits at the splats' rest positions: Noise and Quantise move the points but not the mesh.

Depth of field lens blur

Spark's own per-splat circle-of-confusion blur — a defocused splat is exactly another (wider, dimmer) Gaussian, so this composites correctly through the existing sort with no special handling. 100 is exactly off, on the fast path, not an invisible blur still paying for itself.

Focus is an offset in stops from the pivot, not an absolute distance — the pivot describes what is being looked at, where scene radius describes the whole scan and stops meaning nothing once you have dollied into a detail. Gaussian bokeh only: no aperture shape, no cat's-eye, no shaped highlight discs. Those need a custom splat shader; out of scope here.

Depth fade aerial perspective

Fades opacity and tints toward the current Background colour with distance — dissolves distant splats into the backdrop. No effect at Amount 0.

Renderer-level properties, not per-splat modifiers — these apply to every gaussian on every frame whether or not depth of field is on.

Stretches defocused splats tangentially around the frame centre — the petzval / swirly-bokeh look. Coupled to the amount of defocus, so an in-focus subject stays clean and only the surround swirls. Nothing happens at Depth of field 100.

Mappings band → parameter

To map: arm a band under Map in the transport bar, then click any slider in the panel. Click it again to unmap; Esc when you are done. Depth is how far the band pushes the control, as a fraction of its whole range; negative pushes it down. Audio adds on top of the slider and any keyframes. Low / Mid / High follow loudness in their band, Hit pulses on each detected onset.

Analysed once, offline, not sampled live, so scrubbing, playback and export all read the same values.
